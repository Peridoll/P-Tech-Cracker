# P-Tech: CardMemory — 仕様

## 基本ルール

- カードは5枚。
- 本物の番号は1〜5で、各カードへ重複なくランダムに割り当てる。
- 回答フェーズの表示番号も1〜5だが、本物の番号とは別に並べ替えた偽番号。
- カード位置は記憶フェーズと回答フェーズで変えない。
- 色または図形に関する問題を3問出題する。
- 3問すべて正解で成功。1問でも不正解、または時間切れで失敗。

## 記憶フェーズ

- 制限時間は5秒。
- カードの背景色と本物の番号だけを表示する。
- 本物の番号とカード位置の組み合わせを記憶する。

## 回答フェーズ

- 制限時間は15秒。
- 同じ位置に属性カードを表示する。
- カード下部には偽番号を表示する。
- 各問題の選択肢をタップし、3問を選び終えた時点で自動判定する。

## カード属性

- カードの背景色
- 上に書かれた色名と文字色
- 外側の図形と色
- 内側の図形と色
- 下に書かれた図形名と文字色
- 偽番号の色

色は青、緑、赤、橙、黄、紫、黒、白の8色。

図形は四角、長方形、円、三角の4種類。

## 表示と操作

- BLACK / WHITEテーマをP-Tech全体で共有する。
- スマートフォンでは画面内に自動で収まり、ページスクロールを発生させない。
- タップ、クリック、Escapeキーに対応する。
