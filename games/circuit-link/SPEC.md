# P-Tech: CircuitLink — 仕様

## 基本設定

| 項目 | 値 |
| --- | --- |
| 接続点 | 8個 |
| 配線 | 13本 |
| 初期交差 | 5か所以上 |
| 制限時間 | 30秒 |
| 操作 | ドラッグ |

## ゲーム進行

1. 交差のない正解構造を維持したまま、接続点の初期位置だけをシャッフルする。
2. 初期交差が5か所未満の場合は再生成する。
3. 接続点の移動中に配線と交差数をリアルタイム更新する。
4. 交差している配線は赤、交差のない配線はシアンで表示する。
5. 接続点を離した時点で交差が0なら成功。
6. 30秒経過すると失敗。
