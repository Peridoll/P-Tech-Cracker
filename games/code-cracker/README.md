# CODE CRACKER

4桁の数字コードを60秒以内に当てる、スマホ対応の短時間ミニゲームです。

## Play

`index.html` をブラウザで開くだけで遊べます。外部ライブラリやビルド作業は不要です。

## Current version

- 数字4桁専用
- 同じ数字の重複なし
- 60秒制限
- 判定履歴なし
- 緑 / 黄 / 赤の4連続判定演出
- スマホ用画面内テンキー
- `DELETE` / `ENTER`
- ゲーム中の `EXIT`
- BLACK / WHITEテーマ切替
- PCキーボード対応

詳しい仕様は [`SPEC.md`](./SPEC.md) を参照してください。
