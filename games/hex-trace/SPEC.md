# P-Tech: HexTrace — 仕様

## 基本設定

| 項目 | 値 |
| --- | --- |
| コード形式 | 4桁の16進数 |
| 盤面 | 5列 × 6行（30コード） |
| ターゲット | 6コード |
| 制限時間 | 30秒 |
| 最大ミス | 3回 |

## ゲーム進行

1. ゲーム開始ごとに重複しない30個のコードを生成する。
2. 盤面内のコードから6個をターゲットとして抽出する。
3. ターゲットは上部へ順番に表示し、現在選ぶコードを強調する。
4. 正しいコードを選ぶと盤面から消え、次のターゲットへ進む。
5. 誤選択はミスとして数えるが、3回未満なら続行する。
6. 6コードすべての追跡で成功し、3ミスまたは時間切れで失敗する。

## 操作

- スマートフォン: コードをタップ
- PC: コードをクリック
- Escape: タイトルへ戻る

## 画面

- タイトル画面
- コード探索画面
- 成功 / 失敗結果画面
- EXIT、RETRY、TITLE
- BLACK / WHITE共通テーマ
- スマートフォンではページをスクロールせず画面内へ収める
