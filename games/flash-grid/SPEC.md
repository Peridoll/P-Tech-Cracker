# P-Tech: FlashGrid — 仕様

## 基本設定

| 項目 | 値 |
| --- | --- |
| 盤面 | 7列 × 7行 |
| 点灯数 | 10マス |
| 記憶時間 | 4秒 |
| 再現時間 | 10秒 |
| 操作 | タップ / クリック |

## ゲーム進行

1. ゲーム開始ごとに49マスから重複なしで10マスを選ぶ。
2. 記憶フェーズでは対象の10マスだけを点灯する。
3. 4秒後に全マスを消灯し、再現フェーズへ移る。
4. 正しいマスを選ぶと選択済みとして固定し、発見数を加算する。
5. 10マスすべてを選ぶと成功。
6. 対象外のマスを選ぶか10秒経過すると失敗。

## 画面

- タイトル画面
- 記憶 / 再現ゲーム画面
- 成功 / 失敗結果画面
- EXIT、RETRY、TITLE
- BLACK / WHITE共通テーマ
- スマートフォンではページをスクロールせず画面内へ収める
