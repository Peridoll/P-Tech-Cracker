# P-Tech: RapidSequence — 仕様

## 基本設定

| 項目 | 値 |
| --- | --- |
| レーン | 4 |
| 信号数 | 20 |
| 信号間隔 | 0.7秒 |
| 移動時間 | 2.2秒 |
| 入力判定幅 | 前後0.38秒 |
| 最大ミス | 3回 |

## ゲーム進行

1. ゲーム開始ごとに20個のレーン列をランダム生成する。
2. 信号は0.7秒間隔で出現し、2.2秒かけて判定ラインへ移動する。
3. 判定時刻の前後0.38秒以内に同じレーンを入力すると成功判定になる。
4. 判定外の入力、違うレーンの入力、信号の見逃しはミスとして数える。
5. 20個を判定し、ミスが3回未満なら成功。
6. ミスが3回に達すると即時失敗。

## 操作

- スマートフォン: 画面下部の1〜4ボタン
- PC: 画面ボタン、数字キー1〜4、またはD / F / J / K

## 画面

- タイトル画面
- 追跡ゲーム画面
- 成功 / 失敗結果画面
- EXIT、RETRY、TITLE
- BLACK / WHITE共通テーマ
- スマートフォンではページをスクロールせず画面内へ収める
