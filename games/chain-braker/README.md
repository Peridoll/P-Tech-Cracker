# P-Tech: ChainBraker

オイルリグ強盗の「Same Game」型ギミックを練習するための、スマートフォン対応ミニゲームです。

## Play

`index.html` をブラウザで開くだけで遊べます。外部ライブラリやビルド作業は不要です。

## Current version

- 11列 × 8行
- 赤 / 緑 / 青の3色
- 上下左右でつながった同色グループを消去
- 2個以上のグループだけ消去可能
- 消去後に下詰め、その後に左詰め
- 30秒制限
- 全消去で成功
- 手詰まり / 時間切れで失敗
- スマートフォンでスクロール不要
- BLACK / WHITEテーマ切替

詳しい仕様は [`SPEC.md`](./SPEC.md) を参照してください。
