# P-Tech: CipherType — 仕様

## 基本設定

| 項目 | 値 |
| --- | --- |
| 使用文字 | Q / W / E / R / A / S / D / F |
| コード長 | 15文字 |
| 制限時間 | 7秒 |
| 許容ミス | 0回 |

## ゲーム進行

1. ゲーム開始ごとに15文字のコードをランダム生成する。
2. 同じ文字が連続しないように生成する。
3. 現在入力すべき文字を強調表示する。
4. 正しい入力済み文字は緑色で表示する。
5. 15文字すべてを7秒以内に入力すると成功する。
6. 誤入力または時間切れで即時失敗する。

## 操作

- スマートフォン: 画面内のQWER / ASDFパッド
- PC: 画面ボタン、またはキーボードのQ / W / E / R / A / S / D / F
- Escape: タイトルへ戻る

## 画面

- タイトル画面
- タイピングゲーム画面
- 成功 / 失敗結果画面
- EXIT、RETRY、TITLE
- BLACK / WHITE共通テーマ
- スマートフォンではページをスクロールせず画面内へ収める
