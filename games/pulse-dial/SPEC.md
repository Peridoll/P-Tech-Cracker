# P-Tech: PulseDial — 仕様

## 基本設定

| 項目 | 値 |
| --- | --- |
| 解除段階 | 8 |
| 制限時間 | 30秒 |
| 最大ミス | 3回 |
| 初期判定幅 | 84度 |
| 最終判定幅 | 36度 |
| 初期速度 | 78度 / 秒 |
| 最終速度 | 162度 / 秒 |

## ゲーム進行

1. 各段階で判定エリアの位置と針の回転方向をランダムに決める。
2. 針が判定エリア内にある状態で入力すると段階を解除する。
3. 成功するたびに判定幅を狭め、回転速度を上げる。
4. 判定エリア外での入力はミスとして数える。
5. 30秒以内に8段階すべてを解除すると成功。
6. ミスが3回に達するか、30秒経過すると失敗。

## 操作

- スマートフォン: ダイヤルまたはSYNCボタンをタップ
- PC: クリック、Space、Enter

## 画面

- タイトル画面
- 同期ゲーム画面
- 成功 / 失敗結果画面
- EXIT、RETRY、TITLE
- BLACK / WHITE共通テーマ
- スマートフォンではページをスクロールせず画面内へ収める
